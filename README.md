## 🎯 Purpose of This Mirror

The official installation videos and resource files provided by the manufacturer are originally hosted on **Baidu Netdisk (Baidu Wangpan)**. 

For users outside mainland China or those without a paid VIP account, downloading files from Baidu Drive is often extremely slow, requires dedicated software client installations, or demands local phone number verification. 

To help fellow users and make the setup process smooth and hassle-free, I have re-uploaded and mirrored these installation resources here with direct, unrestricted access.
